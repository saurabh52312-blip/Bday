# Happy Birthday, Shivani 💗

A romantic birthday surprise website (HTML, CSS, vanilla JS). No backend, no framework.

## Folder structure

```
index.html
style.css
script.js
photos/
  photo1.JPG  photo2.JPG  photo3.JPG (hero)  photo4.JPG  photo5.PNG  photo6.JPG
assets/
  birthday-song.mp3   <- ADD YOUR SONG HERE
```

Your photos are already included. Add your song as `assets/birthday-song.mp3`.
File names are case-sensitive on GitHub Pages: keep `.JPG` and `.PNG` in capitals.

## Deploy on GitHub Pages

1. Create a new public repository on GitHub.
2. Click **uploading an existing file**, drag in everything from this folder (with `photos` and `assets`), and Commit.
3. **Settings -> Pages** -> Deploy from a branch -> `main` -> `/ (root)` -> Save.
4. After 1 to 2 minutes: `https://<username>.github.io/<repo-name>/`

## Customize

- Love letter: `index.html`, section `letter-paper`.
- Chapter titles and captions: the `chapter` articles in `index.html`.
- Final surprise message: `gift-card` in `index.html`.

Music starts only after she taps "Open Your Surprise" (browsers block autoplay). If the MP3 is missing, the site still works.
